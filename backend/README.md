# QFit: Backend

Backend Folder

## Dependencies

* uv
* fastapi
* supabase
* qrcode

## Commands

> Get uv as a package manager for python: [download here](https://docs.astral.sh/uv/#__tabbed_1_2)

Check if `uv` exists and validate the version

```sh
uv --version
```

Download all dependencies

```sh
uv sync
```

Run demo

```sh
uv run fastapi dev
```
